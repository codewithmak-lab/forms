# Simple Static Form Website

A clean and responsive static form website built using **HTML** and **CSS**.  
This project is perfect for beginners who want to learn the basics of frontend web development and form design.

## 🚀 Features

- Responsive form layout
- Clean and modern UI
- Pure HTML & CSS
- Beginner-friendly project structure
- Easy to customize
